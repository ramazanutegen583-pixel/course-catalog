# Каталог курсов с корзиной покупок

Самостоятельный учебный проект на Angular 22.2.1, TypeScript и RxJS 7. Все компоненты standalone, формы типизированы и используют Reactive Forms. Интерфейс адаптирован для телефона и компьютера.

## Языки и валюты

В шапке сайта доступны независимые переключатели **Қазақша / English** и **₸ KZT / $ USD**. По умолчанию используются казахский язык и тенге. Выбор сохраняется в `localStorage` под ключом `course-catalog.preferences.v1` и действует на всех маршрутах.

- `src/app/data/translations.ts` — переводы интерфейса, названий, описаний и программ всех курсов.
- `src/app/services/preferences.service.ts` — настройки, локализованное форматирование, расчёт цен и итогов.
- `AppComponent` также обновляет заголовок вкладки и атрибут `html.lang` без перезагрузки.
- Поиск понимает казахские и английские названия независимо от выбранного языка; поиск по исходным русским названиям также сохранён.

Базовые цены хранятся в KZT. Для USD используется **фиксированный курс 1 USD = 441,91 KZT на 02.10.2026** из [публикации Национального банка Казахстана](https://nationalbank.kz/en/exchangerates/ezhednevnye-oficialnye-rynochnye-kursy-valyut). Это сохранённый снимок курса, не живые котировки; дата и пояснение видны внизу сайта. Константа `USD_KZT_RATE` находится в `preferences.service.ts`.

Для долларов цена одного места округляется до центов **до** умножения на количество. Итог складывается из этих сумм в целых центах, поэтому отображаемые строки точно сходятся с итогом. Переключение валют не меняет базовые цены или корзину. Демозаказ сохраняет суммы в обеих валютах, чтобы смена валюты после оформления также работала корректно.

Переводы доступны для загрузки, пустых состояний, ошибок, формы, страницы 404 и неизвестного курса. Если сохранение настроек заблокировано браузером, переключатели продолжают работать в памяти и показывают локализованное сообщение.

## Запуск

Проверено на Node.js 24.19.0 и pnpm. Из этой папки:

```sh
pnpm install
pnpm start
```

Откройте http://localhost:4200. Также можно использовать `npm install` и `npm start`, если npm установлен.

```sh
pnpm build             # production-сборка в dist/course-catalog/browser
pnpm test              # автоматические проверки без watch
```

При размещении на статическом хостинге настройте возврат `index.html` для клиентских маршрутов, чтобы прямое открытие `/course/1` или `/cart` работало.

## Маршруты

| URL | Поведение |
| --- | --- |
| `/` | Перенаправление на `/catalog` |
| `/catalog` | Каталог с поиском по названию и фильтром категории |
| `/course/:id` | Страница курса; для неизвестного ID — «Курс не найден» |
| `/cart` | Корзина и форма оформления |
| Другие адреса | Страница 404 |

`provideRouter(routes)` подключён в `app.config.ts`, страницы загружаются через `loadComponent`. `RouterOutlet` и ссылки находятся в корневом компоненте.

## Данные и живой поиск

`CourseService.getCourses()` возвращает `Observable<readonly Course[]>` с задержкой 450 мс. Поиск не зависит от регистра и игнорирует пробелы по краям; поиск по названию и категория применяются одновременно. `getCourse(id)` возвращает курс либо `undefined` через 350 мс.

В `CatalogComponent`:

```ts
readonly state$ = combineLatest([
  this.search.valueChanges.pipe(
    map(value => value.trim().toLocaleLowerCase('ru')),
    debounceTime(300),
    distinctUntilChanged(),
    startWith(''),
  ),
  this.category.valueChanges.pipe(
    startWith(this.category.value),
    distinctUntilChanged(),
  ),
]).pipe(
  switchMap(([query, category]) =>
    this.courseService.getCourses({ query, category }).pipe(/* состояние и ошибки */),
  ),
);
```

После паузы в вводе `switchMap` отменяет подписку на предыдущий запрос. Фильтр категории реагирует сразу. `startWith` внутри запроса задаёт загрузку, `catchError` внутри `switchMap` позволяет продолжать поиск после ошибки. `AsyncPipe` управляет подпиской и её очисткой. Пример выше сокращён; полный исполняемый код — в `catalog.component.ts`.

## Корзина

`CartService` хранит состояние в приватном signal, наружу предоставляет readonly signal и `computed` для числа мест и общей стоимости. `add`, `remove`, `setQuantity`, `clear` синхронно меняют состояние и сохраняют его. Повторное добавление увеличивает количество в существующей строке.

Количество трактуется как число участников: от 1 до 99. Ноль, дроби и некорректные значения отклоняются; удаление выполняется отдельной кнопкой. Базовые цены заданы в целых тенге (KZT). В интерфейсе доступны KZT и USD.

В `localStorage` под ключом `course-catalog.cart.v1` сохраняется только массив `{ courseId, quantity }`. При загрузке сервис проверяет JSON, ID и количество, исключает дубликаты. Название и цену берёт из актуального массива курсов. При ошибке записи корзина продолжает работать в памяти и показывает сообщение.

Для реального API цены, наличие и итог нужно проверять на сервере при оформлении. Здесь локальные данные служат только демонстрацией.

## Reactive Forms

`CartComponent` использует `FormBuilder.nonNullable.group` и `ReactiveFormsModule`:

- Имя: обязательное, 2–80 символов, не только пробелы.
- Email: обязательный, `Validators.email`, максимум 254 символа.
- Телефон: обязательный, 10–15 цифр; допустимы пробелы, скобки, дефисы и один `+` в начале.

Ошибки отображаются после касания поля или отправки формы. В `checkout()` удаляются пробелы по краям, вызывается `markAllAsTouched()`, проверяются `form.invalid` и наличие товаров.

Оформление демонстрационное: показывает имя, сумму и число мест, затем очищает корзину и поля. Данные не отправляются на сервер; email и телефон не сохраняются в localStorage. При подключении API очищать корзину следует только после успешного ответа сервера.

## Проверки

Автотесты проверяют расчёт суммы, повторное добавление, изменение количества, восстановление после перезагрузки, повреждённое хранилище, ограничения количества, запрет записи в localStorage, задержку и фильтрацию данных, debounce и отмену запросов, валидацию и демонстрационное оформление заказа.

Для ручной проверки: найдите Angular, переключите категорию на «Дизайн», сбросьте фильтры, добавьте курс дважды, измените количество, перезагрузите страницу, проверьте неверную и корректную форму, откройте `/course/999`.

Документация Angular: [Reactive Forms](https://angular.dev/guide/forms/reactive-forms), [Router](https://angular.dev/guide/routing).
